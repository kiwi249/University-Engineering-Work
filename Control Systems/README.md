This folder contains my Control Systems I laboratory coursework on modelling and controlling the Quanser Aero 2 dual-rotor system using MATLAB and Simulink. The work involved identifying rotor and pitch dynamics from experimental data, developing system models and investigating proportional, PI and PID control. Controller responses were assessed through simulation and hardware experiments, comparing tracking performance, steady-state error and transient behaviour.
For Control Systems II, I will extend this work to state-space control using MATLAB and Simulink. The planned laboratory involves analysing unstable systems, designing full-state feedback controllers through pole placement and developing Luenberger observers to estimate unmeasured states. I will then combine the controller and observer into an output-feedback system and investigate how pole selection affects stability, settling time, oscillations and estimation error.
