This folder contains two pieces of robotics coursework. The first focuses on modelling a serial manipulator in CoppeliaSim, using Denavit–Hartenberg parameters and forward kinematics to determine end-effector position from joint angles. The second investigates the Phantom Omni haptic joystick using MATLAB and Simulink, implementing forward and inverse kinematics and comparing calculated results with measured joint angles and end-effector trajectories. It also includes Jacobian analysis to identify singularities.
