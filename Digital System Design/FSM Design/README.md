This folder contains a five-state Moore finite state machine and its VHDL testbench, developed from an individually assigned state diagram for Digital Systems Design II. The design uses a two-bit input to control state transitions and produces three outputs determined by the current state. It separates the state register, next-state logic and output logic, with a synchronous active-high reset. The testbench applies input sequences and uses assertions to check the expected transitions and outputs.
